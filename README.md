# 思思宝宝的专属加油站 🐾

移动端优先的在线刷题与考试应用。纯 HTML5 + CSS3 + JavaScript，无框架、无 CDN、无第三方脚本，不需要 npm install。

## 立即运行

解压后直接双击 `dist/index.html`。应用通过普通 script 加载题库，不使用 fetch，所以无需服务器也可以运行。

开发时推荐使用静态服务器，以获得固定来源下更稳定的 localStorage：

```sh
npx --yes serve dist
```

也可以使用 VS Code Live Server。将 dist 中所有文件部署到任意静态网站服务器即可。手机需访问部署网址；电脑的本地文件路径不能直接作为手机访问链接。通过 file:// 打开时，localStorage 行为由浏览器决定，推荐固定 HTTP/HTTPS 网址。

## 页面与功能

- 首页：思思宝宝专属问候、两种模式入口、已练习题目进度。
- 自由刷题：题库/知识分类选择，单选/多选/判断，查看答案，上一题/下一题，答题卡，收藏与自动错题记录。
- 限时考试：随机抽题，5/10/20/50/100/全部题量，1～180 分钟。请求数量超过可用题量时使用全部可用题目。题目选项顺序保持不变。
- 考试确认：有未答题时显示数量；考试中不揭示正确答案。
- 成绩报告：百分制得分、正确率、用时、按得分分段鼓励、错题与未答题回顾。
- 收藏与错题本：点击单题或整组练习。错题答对后仍保留，可手动选择「已掌握，移出错题本」。
- 成长页：答题总次数、答题正确率、考试最高分、最近 30 场考试，点击记录查看报告。
- 记录导出：导出 JSON 快照供备份、检查或后续开发使用；当前版本没有导入恢复入口。
- 提示音：Web Audio 合成双音，可用右上角开关关闭；浏览器要求先有用户交互。
- 可访问性：44px+ 触控区域、键盘焦点、选项按下状态、状态播报、对话框、减少动画偏好支持。

## 题库来源与导入说明

默认使用用户提供的《附件3：消防安全知识题库(1).docx》。实际导入 346 题，另附 5 道独立功能演示题：

| 分类 | 实际导入 |
| --- | ---: |
| 应急管理基础知识 | 99 |
| 消防安全基础知识 | 197 |
| 消防设计防火知识 | 50 |

原文首页标注 350 题，但第二部分编号跳过了 144、161、188、198，第 15 题虽无编号但已识别导入；第一部分第 22 题没有提供答案，未纳入计分，因此总计 346 题。第二部分第 177 题后另有一行「炮筒 / 喷头 / 折叠部分 / 球阀」的孤立选项，缺少题干及答案，没有当作新题导入。选项标签、空白与内嵌答案标记已经规范化，题意与原答案保持原样。

原附件均为单选题，未提供详细解析，因此附件题目显示原答案和「原题库未提供详细解析」提示。五题演示题库覆盖单选、多选、判断并提供解释，不能把这五题当作原附件的全部内容。

没有对原题答案进行知识性校订；原附件可能包含错字、答案疑点或旧的规范表述，应向出题方确认。应用不把补写的内容伪装成原文解析。

## JSON 题目结构与扩展

```json
{
  "id": "my-question-001",
  "type": "multiple",
  "category": "学习方法",
  "question": "哪些方法有助于复习？（多选）",
  "options": ["回顾错题", "只背字母", "理解正确选项"],
  "answer": [0, 2],
  "explanation": "理解题干和回顾错题能够帮助找到薄弱点。"
}
```

- `id`：全局唯一、长期保持稳定。本地错题/收藏/报告按这个字段关联；不要给原题重新编号。
- `type`：`single` 单选，`multiple` 多选，`boolean` 判断。
- `category`：分类文本；设置页自动读取所有分类。
- `options`：选项数组。判断题使用 `["正确", "错误"]`。
- `answer`：正确选项的 **0 起始下标数组**。单选/判断仅含一个元素。
- `explanation`：详细解析；可以包含换行。所有文本经过 HTML 转义显示。
- `source`、`originalAnswer`：可选的原题库来源与原答案记录。

修改 JSON 后，在项目根目录运行：

```sh
node update-questions.cjs
```

脚本校验数据后更新两个 `.js` 文件；JSON 和 JS 不会自动双向同步。也可直接编辑 JS 数组，但推荐以 JSON 为单一数据源。为保留历史报告可读性，更新题库时应保留原 ID 对应的题目和选项含义。

## 状态与计分逻辑

`app.js` 使用以下状态：`screen` 表示当前页面；`queue` 为本轮题目；`index` 为当前位置；`answers` 按题目 ID 保存选项下标数组；`checked` 防止同一道刷题在一轮中重复计数。

每题等权。答对题数 / 总题数 × 100，四舍五入显示整数分；正确率显示一位小数。多选题必须与标准答案集合完全一致，不计部分分。未答题计错并收录错题本。90～100 分、60～89 分、0～59 分分别显示三种鼓励评价。

已练习进度统计完成答案核对的附件题目去重数量，包含答错题；演示题不计入附件完成进度。累计答题统计每次答案核对/考试判分次数，重复练习会累计。

## localStorage 与续考

- `sisi-study-v1`：收藏、错题、已练习题目、累计次数、最高分、最近 30 场考试及音效偏好。
- `sisi-exam-v1`：考试题目 ID、作答、当前位置、开始时间、绝对截止时间、时长。

倒计时按 `deadline - Date.now()` 计算，每 500ms 更新，避免后台定时器变慢造成计时漂移。刷新后在首页点击「继续考试」恢复题目与答案。页面打开时到期会自动交卷；浏览器完全关闭时无法执行 JavaScript，再次打开会检查截止时间并补交。考试依赖设备时钟，不具备防作弊能力。

所有记录仅留在当前来源的浏览器中，不上传服务器。清理浏览器数据、换设备、换访问域名都可能使旧记录不可见。存储不可用时有提示，当前页面仍可答题，但不能保证刷新后恢复。最高分包含不同题库和不同题量，仅作个人记录。

## 视觉与适配

颜色在 `style.css` 的 `:root` 中集中定义。移动端默认单列，760px 及以上切为双列首页。采用 26px 主卡片圆角、薄荷绿/柔粉模式入口、轻弹按钮、答对飘花、答错陪伴插画。底部导航考虑 iPhone 安全区域，减少动画系统偏好会停用非必要动画。

插画由内置 ImageGen 生成。最终插画提示词概述：奶油背景，头顶橘子的水豚与白色软萌小动物一起读黄色书本，草地、雏菊与薄荷色书本，棕色铅笔线与柔和水彩，无文字。
